# Google Search Console filters

These are report filters, not redirects or robots.txt rules. They do not change ranking, crawling, or indexing. Paste the pattern only, without slash delimiters.

1. Open the Xach Media property in Google Search Console.
2. Go to Performance > Search results.
3. For brand and CEO searches: + New > Query > Custom (regex) > Matches regex. Paste the contents of search-console-query.regex.txt and apply.
4. For the six public pages: + New > Page > Custom (regex) > Matches regex. Paste search-console-pages.regex.txt and apply.
5. Use each filter independently, or apply both to see brand queries for these pages. Switch to Queries or Pages below the chart. Enable clicks, impressions, CTR, and average position. Filters do not create search data; new sites may not have data yet.

# Indexing and brand visibility

Verify domain ownership through Search Console's provided DNS TXT record. Submit https://www.xachmedia.com/sitemap.xml under Sitemaps. Use URL Inspection for the canonical homepage and updated pages, test the live URL, and request indexing when eligible. If a page is excluded, use the reported reason to diagnose it. A site: query is not a complete indexing report.

Use the exact name Xach Media and link to https://www.xachmedia.com/ from your genuine public business profiles. Keep CEO and contact details consistent. Google decides rankings and favicon display; neither regex filters nor deployment can guarantee the top position.
